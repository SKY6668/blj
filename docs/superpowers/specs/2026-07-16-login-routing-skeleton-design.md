# 登录页与路由骨架设计

## 目标

为牙科病例库 MVP 建立可运行的入口和页面导航骨架。用户使用既有的演示账号登录后进入病例列表占位页；其余 MVP 页面均可通过已注册的路由访问。该阶段不实现病例读取、编辑、展示或分享业务。

## 范围

本阶段包含：

- 将 `pages/index/index.uvue` 作为登录页。
- 使用既有 `AuthRepository` 校验演示账号，并在成功后跳转至病例列表页。
- 在登录失败时显示非敏感错误提示。
- 注册病例列表、新建/编辑、病例详情、展示册和分享设置五条路由。
- 为上述五个路由创建占位页，显示页面标题和返回病例列表的入口。

本阶段不包含：

- 病例数据的读取、筛选、保存或删除。
- 表单字段、图片、分享设置或展示册交互。
- 会话路由守卫、真实认证、网络请求或服务端接入。

## 页面与导航

`pages/index/index` 是应用入口。它提供邮箱、密码、登录按钮、演示账号提示和登录失败提示。点击登录时调用 `AuthRepository.login(email, password)`：成功后跳转至 `pages/cases/index`，失败则保持当前页面并显示提示。

`pages/cases/index` 是列表占位页。它显示“病例列表”标题、当前为骨架阶段的说明，以及通往新建病例、病例详情、展示册和分享设置占位页的导航入口。该页不加载病例数据。

`pages/case-edit/index`、`pages/case-detail/index`、`pages/presentation/index` 和 `pages/share-settings/index` 仅显示对应标题、功能尚未实现的说明，以及返回病例列表的入口。

## 结构与依赖

路由全部在 `pages.json` 注册。登录页只依赖 `src/data/auth-repository.ts` 导出的仓库创建函数和现有 `src/data/storage.ts` 存储适配器；占位页不直接访问数据层或 `uni` 存储 API。

为避免跨页面重复逻辑，返回入口统一跳转到 `pages/cases/index`。本阶段不传递病例 ID，因此详情、新建和分享页面均为静态占位页面。

## 错误处理与隐私

登录失败仅显示“演示账号或密码不正确”之类的通用提示，不记录或持久化输入的密码。成功登录后由现有仓库只持久化非敏感会话信息。页面不显示真实患者信息、真实图片、分享链接或二维码。

## 验证

- 新增或调整测试，验证 `pages.json` 已注册六条页面路径且入口为登录页。
- 保留并运行现有认证仓库测试，确认成功登录仅保存非敏感会话，错误凭据不会创建会话。
- 运行全部单元测试。
- 在 HBuilderX CLI 连接可用时执行 H5 构建；若连接不可用，明确报告为环境阻塞，不将其判定为构建成功。

## 完成标准

- 从登录页可以用演示账号进入病例列表占位页。
- 错误凭据显示失败提示且不跳转。
- 六条页面路由均已注册，病例列表可进入四个后续占位页并返回。
- 本阶段没有新增病例业务逻辑或网络能力。
